## Before You Start

You'll need:

- WordPress 5.8 or higher
- PHP 7.4 or higher
- Admin access to your WordPress site

---

## Quick Path

1. **Install the plugin** from WordPress.org
2. **Create an ad** with your image or code
3. **Select a placement** (header, sidebar, etc.)
4. **View your site** - ad is live

That's it for basic usage.

---
