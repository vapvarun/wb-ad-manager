## Quick Reference

### Create Your First Ad

1. Go to **WB Ad Manager > Ads > Add New**
2. Enter a title (internal use)
3. Select ad type (Image, Code, etc.)
4. Add your content
5. Select placements
6. Click **Publish**

### Display an Ad

**Widget:** Appearance > Widgets > Add "WBAM Ad Widget"

**Shortcode:** `[wbam_ad id="123"]`

**PHP:** `<?php echo do_shortcode('[wbam_ad id="123"]'); ?>`

## Common Tasks

| Task | Where |
|------|-------|
| Create ad | WB Ad Manager > Ads > Add New |
| Edit ad | WB Ad Manager > Ads > Click ad title |
| Enable/disable ad | Edit ad > Toggle "Enabled" |
| View stats | WB Ad Manager > Ads > Clicks/Impressions columns |
| Create link | WB Ad Manager > Links > Add New |
| View link stats | WB Ad Manager > Links > Click column |
| Plugin settings | WB Ad Manager > Settings |
