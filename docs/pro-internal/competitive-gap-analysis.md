# WB Ad Manager — Competitive Gap Analysis & Roadmap

**Date:** 2026-03-17
**Compared Against:** HivePress, Directorist, WPAdverts, Classified Listing Pro, Advanced Ads, AdSanity

---

## Where We Lead (Unique Strengths)

- **Unified Ads + Classifieds** — No competitor combines ad management AND classifieds in one plugin
- **Wallet/Credits System** — Built-in digital wallet, 5 payment gateways, atomic transactions, idempotency
- **Campaign Management** — CPM/CPC/Flat campaigns with budget reservation (ad-server level)
- **Full Advertiser Portal** — 15-tab dashboard, far more comprehensive than competitors
- **Deep BuddyPress/BuddyBoss Integration** — Profile tabs, activity feed, notifications
- **A/B Testing** — Built-in split testing (only Advanced Ads Pro has this among competitors)
- **Email Capture Ads** — Built-in lead generation unique to our plugin
- **Affiliate Link Module** — Partnership requests, commission tracking

## Critical Gaps (All major competitors have these)

### 1. Map/Geolocation Search
- Google Maps or OpenStreetMap integration
- Radius/proximity search ("within 10km")
- Map view for browse page
- Geocoding on listing submission (address → lat/lng)
- **Competitors:** HivePress, Directorist, Classified Listing Pro, WPAdverts all have this

### 2. Reviews/Ratings
- Buyers rate sellers (1-5 stars + text review)
- Average rating display on seller profile
- Review moderation by admin
- Verified purchase reviews (optional)
- **Competitors:** HivePress, Directorist, Classified Listing Pro

### 3. Custom Fields Builder (Drag & Drop)
- Visual form builder for admins
- Custom fields per category (e.g. "Mileage" for Cars, "Bedrooms" for Real Estate)
- Field types: text, number, select, checkbox, radio, date, URL, color
- Fields appear in search filters automatically
- **Competitors:** HivePress, Directorist (drag & drop), Classified Listing Pro (AI-powered)

### 4. Private Messaging / Live Chat
- Real-time messaging between buyers and sellers
- Message threads per listing
- Email notification on new messages
- Block/report functionality
- **Competitors:** HivePress, Directorist, Classified Listing Pro (live chat)

### 5. Membership/Subscription Plans
- Recurring monthly/yearly plans
- X listings per plan
- Featured listings included in higher tiers
- WooCommerce Subscriptions integration
- **Competitors:** Directorist (30+ add-ons), Classified Listing Pro (Store addon), WPAdverts

## High Priority Gaps

### 6. Seller Store Pages
- Dedicated store page per seller with banner, description, hours
- All seller's listings on one page
- Store URL (e.g., /store/seller-name/)
- **Competitors:** Classified Listing Pro (most popular addon), HivePress, Directorist

### 7. Social Login
- Google/Facebook/Apple login
- One-click registration
- **Competitors:** HivePress, Directorist, Classified Listing Pro

### 8. Email Alerts / Saved Searches
- Users save search criteria
- Email notification when new matching listings appear
- Manage saved searches from profile
- **Competitors:** Directorist, Classified Listing Pro

### 9. Schema/SEO Markup
- Product/Offer structured data for listings
- LocalBusiness schema for sellers
- Better Google rich snippets
- **Competitors:** Directorist, Classified Listing Pro

### 10. CSV Import/Export
- Bulk import listings from CSV
- Export listings for backup/migration
- Column mapping UI
- **Competitors:** Directorist, Classified Listing Pro

## Ad Management Gaps (vs Advanced Ads)

### 11. Ad Blocker Detection
- Detect ad blockers and show alternative content
- Overlay with customizable message
- Fallback ads for blocked placements
- Advanced Ads' most popular Pro feature

### 12. Google Ad Manager (GAM/DFP)
- Integration with Google's ad server
- Programmatic ad serving
- Multiple ad network support

### 13. Click Fraud Protection
- Bot pattern detection beyond rate limiting
- Competitor click detection
- Invalid traffic filtering

### 14. Google Analytics Integration
- Track ad impressions/clicks as GA4 events
- Revenue tracking in GA
- Custom dimensions for ad campaigns

### 15. Video Ad Type
- Native video ad support (not just HTML embed)
- Autoplay/mute options
- VAST/VPAID support
